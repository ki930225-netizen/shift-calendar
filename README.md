# 근무 캘린더 (광고 없는 교대근무 앱) v2

## 화면 구성 (하단 탭)
- **캘린더**: 한 달 전체 화면. 날짜 칸에 근무 원(D·A·F·N·주·야·휴·대체·보상), 공휴일 이름(빨강), 목요일 주차, 음력(1일·15일), 근태(연차 등), 메모 띠(여러 날에 걸쳐 색 띠로 표시)
  - 날짜를 누르면 아래에서 시트가 올라옴: **메모 탭**(새 메모/일정 목록) · **근무 탭**(근무 눌러 적용, 근태 선택·편집)
  - 우측 상단 달력 연필 아이콘 = **근무 연속 입력**: 근무를 하나 고른 뒤 날짜를 차례로 누르면 바로 입력
- **알람**: 근무별 알람. "이 근무인 날, 이 시각(24시간제)에 울려라". 다음 알람까지 남은 시간 표시, 켜기/끄기 스위치
- **설정**: 패턴 일괄 적용, 공휴일/구글 캘린더 연동, 백업·복원

## 메모
제목, 글자색·배경색, 할 일(체크), 기간(시작·종료 날짜/시간, 하루 종일), 알림(정각~1일 전). 기간이 여러 날이면 달력에 이어진 띠로 표시됩니다.

## 공휴일
- 구글 "대한민국의 휴일" 캘린더를 앱을 열 때마다 가져옴
- 인터넷이 없어도 양력 고정 공휴일 + **설날·추석·부처님오신날은 앱이 직접 계산**(한국 시간 기준 음력, 2048년까지)

## 설치 / 업데이트
- GitHub에 파일을 올리면 Actions가 APK를 자동으로 만듭니다 (아래 순서). 만든 APK를 폰에 설치하면 기존 앱 위에 덮어써지고 데이터가 유지됩니다.
- `release.keystore`는 지우거나 바꾸지 마세요.

### GitHub으로 APK 받기
1. 저장소에 `lib`, `.github`, `pubspec.yaml`, `setup.py`, `release.keystore`, `README.md` 를 올립니다. (`.github/workflows/build-apk.yml`은 점(.) 폴더라 직접 만들어야 할 수 있음)
2. Actions 탭에서 빌드 완료(5~10분) → 맨 아래 Artifacts의 `shift-calendar-apk` 다운로드 → 안의 `app-release.apk`를 폰으로 옮겨 설치
3. 실패(빨간 X)하면 실패한 단계의 로그를 복사해서 보내주세요.

### PC 미리보기 (선택)
`python3 setup.py` → `cd app` → `flutter run -d chrome` (알람·구글 동기화는 웹에서 동작 안 함)

## 구글 캘린더(제미나이 일정) 연동
1. calendar.google.com → 캘린더 옆 ⋮ → 설정 및 공유 → "iCal 형식의 비공개 주소" 복사
2. 앱 설정 탭 → 주소 붙여넣기 → 지금 동기화
- 구글 "할 일(Tasks)"은 연동되지 않습니다. 제미나이에게 "구글 캘린더에 일정으로 추가해줘"라고 하세요.
- 비공개 주소는 비밀번호와 같으니 남에게 보여주지 마세요.

## 알람이 확실히 울리게 (갤럭시)
- 알림 허용, "알람 및 리마인더" 허용
- 설정 → 앱 → 근무 캘린더 → 배터리 → **제한 없음**
- 앱은 열 때마다 앞으로 60일치 근무 알람을 다시 등록합니다. 두 달 이상 안 열면 알람이 끊깁니다.

## 한계
- 알람은 "알림 + 알람 소리" 방식이라 방해금지 모드를 뚫지 못할 수 있습니다.
- 구글 반복 일정은 매일/매주/매월/매년 기본 형태만 펼쳐서 보여줍니다.
- v1(이전 버전)에서 입력한 근무는 v2로 옮겨지지 않습니다.

## v2.1 변경 사항

- **알람**: 요일 반복 · 당일/전날/다음날 · 알람음 4종(벨·삐삐삐·멜로디·차임)+폰 기본음 · 진동 · 알람 메모 · 알람 볼륨 슬라이더(폰의 "알람" 볼륨)
- **알람 상태 점검**: 알람 탭에서 알림/정확한 알람 권한 확인, "지금 소리 테스트", "10초 뒤 테스트"
- **대체공휴일** 자동 계산 (인터넷 없이도 표시) + 공휴일 칸에 **빨간 띠**
- **쉬는 날 입력**: 달력 위 버튼(이번 달) 또는 설정 > "쉬는 날 휴로 일괄 입력" — 토·일·공휴일 선택
- **패턴 적용**: "쉬는 날은 휴로, 나머지 날에만 패턴 이어가기" 옵션 (패턴 순서가 쉬는 날을 건너뜀)
- 빌드 시 `setup.py`가 알람음 파일과 안드로이드 연결 코드를 자동으로 만들어 넣습니다. (GitHub에는 `lib` 폴더, `pubspec.yaml`, `setup.py` 만 올리면 됩니다.)

## v2.2 변경 사항

- **폰 캘린더 직접 연동**: 설정 > "폰에 등록된 캘린더 바로 가져오기" (구글/삼성 캘린더 일정이 주소 입력 없이 나옴)
- **월별 메모**: 달력 맨 아래 줄을 눌러 입력
- **주별 패턴**: 달력 위 `주별 패턴` 버튼 — 요일별 근무 + 쉬는 날은 휴 + 쉬는 날 전날 근무 + 미리보기
- **알람 시각 직접 입력**: 숫자를 누르면 바로 키보드
- **알람 안정화**: 알람시계 방식 예약, 같은 알람은 덮어쓰기(중간에 멈춰도 사라지지 않음), 앱으로 돌아올 때 재등록, 배터리 제한 해제 요청, 불러오기 실패 시 저장 차단(데이터 보호)

## v2.2.1 변경 사항

- **저장 이중화**: 설정저장소 + 앱 전용 파일, 두 곳에 저장하고 시작할 때 더 최근 것을 사용
- **저장 상태 점검**: 설정 맨 아래에서 불러온 곳 / 현재 데이터 개수 / 마지막 저장 결과 / 저장 테스트 확인

## v2.3 변경 사항

- **알람 전 미리 알림**: 알람 N분 전(기본 20분)에 알림창에 "N분 뒤 알람"이 카운트다운과 함께 뜨고, **"이번 알람 끄기"** 버튼으로 그 회차만 끌 수 있음
- **알람 상태 자동 갱신** + **마지막 등록 결과**(알람시계/정확/부정확/실패 개수, 오류 내용) 표시
- 테스트 버튼 3종: 지금 소리 / 10초 뒤 / 2분 뒤(앱 종료 후 확인용)

## v2.4 변경 사항
- 알람이 울릴 때 알림창에 버튼이 생겼어요: **5분 후 다시 울림 / 10분 후 다시 울림 / 알람 종료**
- 다시 울림은 같은 소리·진동으로 5분(또는 10분) 뒤에 한 번 더 울려요.

## v2.4.1 변경 사항
- 알람 탭에 "알람 N개 · 근무 입력된 날 N일 · 60일 안 울릴 근무 알람 N회" 요약 표시 (0회면 이유 안내)
- "근무 알람 지금 다시 등록" 버튼, 자동 등록이 실패/멈추면 사유 표시, 멈춘 등록은 1분 뒤 자동 해제
