# 근무 캘린더 (광고 없는 교대근무 앱)

## 기능
- 월간 캘린더에 근무(주/오/야/휴 등)를 색깔 원으로 표시, 이번 달 근무 일수 합계
- 날짜를 누르고 근무 종류 선택 / 지우기
- **패턴 일괄 적용**: 예) 주→주→야→야→휴→휴 를 시작일부터 30~365일 반복 입력
- **날짜별 메모**: 날짜마다 여러 개 추가/삭제, 달력 칸에도 표시
- **날짜별 알람**: 근무 종류별 기본 알람(출근 정각~6시간 전) + 특정 날짜만 원하는 시각으로 지정 / 그날 알람 끄기
- **공휴일 자동 표시**: 구글 "대한민국의 휴일" 캘린더를 앱을 열 때마다 가져옴 (설날·추석·대체공휴일 포함, 앞으로 2년치). 인터넷이 안 될 때는 양력 고정 공휴일(신정·삼일절·어린이날 등)이 기본 표시됨
- **구글 캘린더 연동**: 제미나이가 구글 캘린더에 등록한 일정이 앱 달력에 자동 표시 (아래 설정 방법)
- 알람은 앱을 꺼도 울리고, 폰 재부팅 후에도 유지
- 데이터는 모두 폰 안에만 저장 (광고/로그인/서버 없음)

## 설치 방법 (PC에서 1회)
1. Flutter SDK 설치: https://docs.flutter.dev/get-started/install (`flutter doctor` 통과)
2. 이 폴더에서 실행:
   ```
   python3 setup.py
   cd app
   flutter build apk --release
   ```
3. `app/build/app/outputs/flutter-apk/app-release.apk` 를 폰으로 보내 설치

## 구글 캘린더(제미나이 일정) 연동
1. PC에서 calendar.google.com → 연결할 캘린더 옆 ⋮ → 설정 및 공유
2. "캘린더 통합" → **iCal 형식의 비공개 주소** 복사
3. 앱 우측 상단 구름 아이콘 → 주소 붙여넣기 → "지금 동기화"
- 이후 앱을 열 때마다 자동 갱신됩니다.
- 제미나이에게는 "구글 캘린더에 일정으로 추가해줘"라고 요청하세요.
- **구글 "할 일(Tasks)"은 이 방식으로 연동되지 않습니다.** (Tasks 연동은 구글 로그인 API 설정이 필요해서 별도 작업)
- 비공개 주소는 비밀번호와 같으니 남에게 공유하지 마세요.

## 갤럭시에서 알람이 확실히 울리게
- 알림 허용, "알람 및 리마인더" 허용
- 설정 → 앱 → 근무 캘린더 → 배터리 → **제한 없음**
- 앱은 열 때마다 앞으로 60일치 알람을 다시 등록합니다. 두 달 이상 안 열면 알람이 끊깁니다.

## 한계
- 알람은 "알림 + 알람 소리" 방식이라 방해금지 모드를 뚫지 못할 수 있습니다.
- 구글 반복 일정은 매일/매주/매월/매년 기본 형태만 펼쳐서 보여줍니다.
- 시간대는 한국(Asia/Seoul) 고정입니다.

## PC 크롬에서 미리보기 (폰 없이 화면 확인)
```
python3 setup.py
cd app
flutter run -d chrome
```
- 달력·근무 입력·패턴·메모 화면 확인용입니다. 알람은 동작하지 않습니다(폰 전용).
- 크롬 보안 정책(CORS) 때문에 구글 공휴일/캘린더 동기화는 웹에서 실패할 수 있습니다. 이 경우 양력 공휴일만 표시됩니다. 폰 앱에서는 정상 동작해야 합니다.
- 크롬 창 폭을 좁게 줄이면 폰 화면과 비슷하게 보입니다.

## GitHub으로 APK 받기 (PC에 Flutter 설치 불필요)
1. github.com 가입 → 우측 상단 + → New repository → 이름 `shift-calendar`, **Private** 선택 → Create
2. "uploading an existing file" 링크 → 이 폴더 안의 파일/폴더(`lib`, `.github`, `pubspec.yaml`, `setup.py`, `README.md`, `.gitignore`)를 끌어다 놓기 → Commit changes
   - `.github` 폴더가 안 올라가면: Add file → Create new file → 이름에 `.github/workflows/build-apk.yml` 입력 → 파일 내용 붙여넣기
3. 위쪽 **Actions** 탭 → Build APK 실행(자동 시작됨, 안 되면 Run workflow) → 5~10분 대기
4. 초록 체크가 뜨면 그 실행을 클릭 → 맨 아래 Artifacts의 `shift-calendar-apk` 다운로드 → zip 안의 `app-release.apk`를 폰으로 옮겨 설치
5. 빨간 X(실패)면 실행 → 실패한 단계의 로그를 복사해서 보내주세요.

## PC 브라우저에서 인터넷 주소로 열어보기 (GitHub Pages)
1. 저장소를 **Public**으로 두세요 (무료 계정은 Private 저장소에서 Pages를 쓸 수 없음). 코드에는 개인 정보/주소가 들어있지 않고, 근무·메모·iCal 주소는 각자 브라우저/폰에만 저장됩니다.
2. 저장소 Settings → Pages → Source를 **GitHub Actions**로 선택
3. Actions 탭에서 빌드가 끝나면(deploy 초록 체크) 주소가 `https://내아이디.github.io/shift-calendar/` 로 열립니다.
- 웹 버전은 화면 확인용입니다. 알람과 구글 캘린더 동기화는 되지 않을 수 있습니다.
- 웹에 입력한 데이터는 그 브라우저에만 저장되고 폰과 공유되지 않습니다.

## 업데이트(패치) 방법
1. 수정된 파일을 GitHub 저장소에 같은 이름으로 다시 올려 덮어쓰기 (zip 안의 파일 전체를 다시 올려도 됨)
2. Actions 탭에서 빌드 완료(5~10분) → 새 APK 다운로드 → 폰에서 그 APK를 설치하면 **기존 데이터 그대로** 덮어써집니다.
- `release.keystore`(서명 키)를 저장소에서 지우거나 바꾸지 마세요. 바뀌면 업데이트가 안 되고 앱을 지워야 합니다.
- 만약을 위해 앱의 구름 아이콘 → "백업 복사"로 근무표를 카톡 "나와의 채팅"에 보관해 두세요.
